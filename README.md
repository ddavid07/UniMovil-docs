## Alcance y límites

Este repositorio reúne requisitos, catálogo funcional, metodología, backlog, iteraciones, actas, validación, investigación, memoria, presentaciones y documentos históricos. No es la fuente de arquitectura, API, instalación, seguridad ni decisiones técnicas: esos documentos permanecen junto al código en UniMovil.

El contenido se actualizará a medida que el equipo confirme información. Las plantillas no representan reuniones o resultados reales. No añadas secretos ni datos personales identificables.
