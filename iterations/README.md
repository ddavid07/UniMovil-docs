# Iteraciones

Documenta cada iteración en un archivo o subdirectorio con nombre inequívoco, por ejemplo, iteration-01/README.md. No crees una carpeta llamada Scrum.

Cada registro puede incluir:

- objetivo;
- alcance e historias incluidas;
- incremento producido;
- evidencias verificables;
- revisión del incremento;
- retrospectiva y cambios acordados;
- trabajo pendiente y riesgos conocidos.

Plantilla: deja los campos sin completar o márcalos como pendientes hasta que existan datos confirmados. No inventes fechas ni resultados. La planificación es evolutiva y una iteración documentada no compromete el orden del resto del proyecto.
