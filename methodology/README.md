# Metodología de trabajo

El proyecto utiliza un enfoque ágil basado en Scrum. La planificación es evolutiva: no existe un plan cerrado e inmutable para todo el proyecto.

El backlog se prioriza y refina conforme se aprende y cambian las necesidades. El trabajo se organiza por iteraciones, y cada iteración debe producir un incremento verificable o documentar con claridad qué se pudo validar. Al cerrar una iteración, el equipo puede revisar decisiones y ajustar el modo de trabajo.

Las reuniones, roles, duración y resultados concretos se documentarán cuando estén confirmados. Esta descripción del enfoque no afirma que haya ocurrido una ceremonia o revisión concreta.
