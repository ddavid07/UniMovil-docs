# Validación y evidencias

Registra cómo se validan requisitos e incrementos: pruebas, feedback, sesiones con usuarios, criterios observados y evidencias. Para cada evidencia indica el requisito relacionado, el método, el resultado confirmado, el contexto relevante y la fecha cuando se conozcan.

No publiques datos personales, credenciales, ubicaciones privadas ni capturas que los contengan. Distingue feedback recibido de conclusiones del equipo. Si todavía no hay resultados, conserva solo esta guía o usa una plantilla vacía; no inventes validaciones.
